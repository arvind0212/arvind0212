I build production-grade agentic systems, mostly in healthcare. Most of the work is context and harness engineering: giving models the right information, tools and checks, using them where they are strong, and leaving the rest to deterministic code and human review.

### Selected work

**[Agentic clinical ETL benchmark](https://github.com/arvind0212/agentic-clinical-etl-benchmark).** My master's thesis at Karolinska Institutet, in collaboration with Arkus AI. A synthetic benchmark that tests whether LLM agents preserve clinical meaning when they standardise messy health records to OMOP, and what extra tools cost in reliability, tokens and runtime.

**[Circles](https://github.com/arvind0212/social_circle_manager).** A group-planning app built at the Microsoft, KTH AI and SSE hackathon. Gemini scores candidate events for each member, the group votes, and the winner becomes a shared plan. Flutter, FastAPI and Supabase. [Watch the demo](https://youtube.com/shorts/_cu9Ob0BEsE).

**Household** *(launching soon)*. A shared household app with an MCP server, so each member's own agent can turn receipts and voice notes into expense drafts that a person confirms before anything posts.

**Ambient** *(launching soon)*. A Windows desktop interface that brings an existing AI agent into any app, with visible context, approvals and safe paste-back.

**[Canvas Calendar Sync](https://github.com/arvind0212/Canvas-Calendar-Sync).** Pulls assignment deadlines from KTH and KI Canvas into Google Calendar on a schedule, without creating duplicates.
